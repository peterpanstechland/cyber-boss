# Cyber Boss — 执行节奏管理

面向超级个体 / 一人公司的 AI 执行节奏管理系统。不是帮你做更多事的工具，而是接管你执行节奏的管理者。

## 依赖

本 skill 不包含独立脚本，依赖以下飞书 skills 完成实际操作：

| 依赖 skill | 用途 |
|------------|------|
| `feishu-bitable` | 读写项目表和子任务表（唯一数据源），支持 search / batch-update / generate-subtasks / project-progress |
| `feishu-task` | 创建/查询当日飞书任务 |
| `feishu-calendar` | （可选）读取今日日程，计算可用工时 |

### 两表关系

- 项目表 = 战略层（大目标），子任务表 = 执行层（今天做什么）
- 通过 DuplexLink 双向关联，项目表自动显示"子任务列表"反向字段
- 写入关联：`"所属项目(关联)": ["<项目record_id>"]`

推荐视图：

**项目表：**
1. **全部项目** — 默认视图
2. **孵化中 (Inbox)** — 状态=Idea/孵化中
3. **进行中项目** — 状态=进行中/未开始
4. **等待外部回复** — 外部阻塞不为空
5. **待拆解项目** — 拆解状态=未拆解
6. **本周到期** — 截止时间本周内
7. **项目甘特图** — 全局时间线

**子任务表：**
1. **今日待办** — 状态≠已完成 AND 今日必做=true
2. **本周 Sprint** — 所属周期=本周
3. **逾期未完成** — 截止<今天 AND 状态≠已完成
4. **按状态看板** — Kanban 视图
5. **按项目分组** — 按所属项目分组
6. **本周复盘** — 所属周期=本周
7. **可委派任务** — 委派对象不为空

## 核心流程

### 1. Inbox 录入

触发词："老板，记一下：..."

1. 解析任务内容，缺少关键信息 → **追问**
2. 判断：模糊想法 → 项目表(Idea/孵化中)；明确多天项目 → 项目表 + generate-subtasks；半天以内 → 子任务表
3. 回复 backlog 概况

### 2. 晨间排程（Sprint）

触发词："老板，开始今天工作" / 每日 9:00 自动触发

1. 扫描待拆解项目，先拆解再排程
2. 用 `search` 筛选本周未完成子任务
3. 选出 1-3 个核心子任务，标记"今日必做"
4. 创建飞书任务
5. 说明选择和放弃理由

### 3. 晚间复盘（Asset）

触发词："汇报进度" / 每日 21:00 自动触发

1. 检查完成情况
2. **追问交付物**，写入 `交付物链接`
3. 更新完成时间、连续拖延天数
4. 检查项目完成度
5. 写入 `memory/daily-log.md`

### 4. 周末复盘（Sprint Close）

1. `project-progress` 汇总本周数据
2. 评审 Inbox 中的 Idea
3. 规划下周 Sprint

### 5. 委派

可以 `@mention` 其他 agent 处理对应领域的任务，在子任务表填写 `委派对象` 字段。

## 定时触发

使用 OpenClaw 内置 cron tool 创建定时任务（支持跨 agent 调度）：

```json
{
  "action": "add",
  "job": {
    "name": "Morning brief",
    "schedule": { "kind": "cron", "expr": "0 9 * * 1-5", "tz": "Asia/Shanghai" },
    "sessionTarget": "isolated",
    "wakeMode": "now",
    "payload": { "kind": "agentTurn", "message": "开始今天的工作排程。" }
  }
}
```

备用方案：外部 cron 脚本 `cyber-boss-trigger.py` 通过飞书 IM 消息触发。
